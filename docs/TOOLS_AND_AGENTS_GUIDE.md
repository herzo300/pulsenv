## 2. ⚡ RepoWise: Экономия токенов и граф кодовой базы
* **Установлено**: Глобальный пакет `repowise` (v0.1.99)
* **Зачем нужен**: Создает быстрый граф вызовов и зависимостей проекта (`tree-sitter`), сокращая расход токенов LLM на 60–90% при работе с Cursor, Claude Code, Windsurf и Antigravity.
* **Основные команды в терминале**:
  ```bash
  # 1. Создать локальный индекс репозитория:
  repowise create

  # 2. Запустить фоновый слушатель изменений:
  repowise start

  # 3. Интегрировать с вашими AI-инструментами:
  repowise tools
  ```

## 3. 🎨 Onlook: Визуальный редактор React / Next.js
* **Установлено**: `@onlook/cli`
* **Что это**: Инструмент прямого визуального редактирования веб-интерфейсов на React / Tailwind CSS прямо из браузера с мгновенной записью изменений в исходный код.
* **Как использовать**:
  1. В папке любого React или Next.js проекта выполните:
     ```bash
     npx @onlook/cli
     ```
  2. Запустите проект: `npm run dev`.
  3. В открывшемся Onlook Studio нажимайте на любые кнопки, карточки и тексты, меняйте стили и отступы визуально — изменения сразу попадут в `.tsx`/`.jsx` файлы!

## 4. 🧠 Навыки Nous Research Hermes Agent & Паттерны «500 AI Agents»
Гермес переведен на современный стандарт автономных процедур (`SKILL.md`) и оснащен мульти-агентным оркестратором:
* **Triage Agent**: Мгновенный скоринг срочности и опасности сигнала (0–10).
* **Geo-Spatial Locator**: Привязка к координатам, домам и управляющим компаниям.
* **Utility Cross-Checker**: Сверка с журналами Горводоканала, НЭСКО, УТВ, ЕДДС-112.
* **Visual Verifier**: VLM-анализ фотографий и видеопотоков набережной р. Обь и городских парковок.
* **Action Dispatcher**: Точечная push-рассылка жителям затронутых домов.
