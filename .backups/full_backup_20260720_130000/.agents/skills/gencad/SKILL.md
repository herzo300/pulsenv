# GenCAD: Generative 3D CAD Design Skill

`GenCAD` — это инструмент на базе глубокого обучения для генеративного дизайна и автоматического создания 3D CAD моделей (в форматах STL/STEP/IGES) на основе текстовых описаний или параметров.

## 🚀 Назначение в проекте City Pulse
- **Моделирование городской инфраструктуры:** Генерация 3D объектов благоустройства (скамейки, ограждения, урны, элементы детских площадок) для визуализации проектов благоустройства Нижневартовска.
- **Интеграция с AutoCAD/Blender MCP:** Экспорт сгенерированных моделей напрямую в AutoCAD или Blender через соответствующие MCP-серверы для дальнейшего редактирования.

## 🛠️ Настройка и Запуск

Инструмент требует установленного Python и зависимостей PyTorch.

1. Установите зависимости с помощью Conda или pip:
   ```bash
   pip install -r requirements.txt
   ```
2. Для генерации 3D модели выполните инференс:
   ```bash
   python inference_gencad.py --prompt "bench with backrest" --output results/bench.stl
   ```
3. Конвертация STL в изображение для предпросмотра на карте или дашборде:
   ```bash
   python stl2img.py --input results/bench.stl --output results/bench.png
   ```

## 📊 Основные файлы скрипта
- `train_gencad.py` — Скрипт обучения модели генеративного дизайна.
- `inference_gencad.py` — Скрипт генерации 3D объектов по промптам.
- `stl2img.py` — Утилита визуализации сгенерированных 3D-моделей в виде PNG-изображений.
