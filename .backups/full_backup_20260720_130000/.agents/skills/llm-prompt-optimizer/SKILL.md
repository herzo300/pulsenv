# LLM Prompt Optimizer — City Pulse / СообщиО

Оптимизация промптов для AI-конвейера городской системы мониторинга. Три уровня провайдеров с fallback-цепочкой, чтобы система работала даже при отсутствии интернета.

## 🎯 Применять когда

- Оптимизация промптов классификации жалоб (категории: ямы, освещение, ЖКХ, двор и т.д.)
- Промпты для AI Report Verification (zai_vision_service.py — сравнение фото с текстом)
- Промпты для daily_digest (ежедневная AI-сводка по городу)
- Промпты для VLM (`/vlm/describe` — описание изображений камер/жалоб)
- Структурированный JSON-вывод для извлечения адресов (→ геокодирование)
- Снижение галлюцинаций при классификации

## 🤖 AI-провайдеры проекта (fallback chain)

| Приоритет | Провайдер | Модель | Назначение | Где |
|-----------|-----------|--------|------------|-----|
| 1 | **Z.AI** (облако) | GLM-5 Turbo (текст), GLM-4V (vision) | Основной текст + vision | `zai_vision_service.py` |
| 2 | **LiteLLM → Ollama** (локально) | Gemma 4 E4B | Локальный автономный (текст + vision) | контейнер `ollama` (port 11434) + `litellm` (4000) |
| 3 | **Keyword** (детерминированный) | — | Fallback без ИИ | в коде проекта |

## 🧱 Ключевые паттерны промптов проекта

### 1. Классификация жалобы (структурированный вывод)

```
Ты — аналитик городских жалоб для Нижневартовска.
Классифицируй жалобу по ОДНОЙ из категорий:
- "road" (ямы, дорожное покрытие)
- "lighting" (освещение улиц)
- "housing" (ЖКХ, фасады, подвалы)
- "yard" (двор, детские площадки)
- "trash" (мусор, несанкционированные свалки)
- "transport" (остановки, парковка)
- "other"

Извлеки адрес формата "улица + номер дома" (если есть).

Верни ТОЛЬКО валидный JSON, без объяснений:
{"category": "...", "address": "...", "confidence": 0.0-1.0}

Текст жалобы: """{user_text}"""
```

### 2. AI Report Verification (zai_vision_service.py)

```
Сравни текст жалобы с фотографией и оцени соответствие.

Текст жалобы: "{report_text}"
Категория из жалобы: "{category}"

Задача:
1. Опиши, что РЕАЛЬНО на фото.
2. Оцени, соответствует ли фото заявленной категории (0.0-1.0).
3. Если описание "Яма", а на фото "Машина" — confidence низкий.

Верни JSON:
{"description": "...", "verification_score": 0.0-1.0, "mismatch_reason": "..."}

Если фото не соответствует — verification_score < 0.5.
```

### 3. Daily Digest (ежедневная сводка города)

```
Ты — редактор городской сводки Нижневартовска.
На основе списка инцидентов за день создай краткий дайджест:
- 3-5 главных тем дня
- Тон: информативный, без паники
- Объём: до 500 знаков
- На русском языке

Инциденты за день: {incidents_json}

Формат: Markdown с эмодзи-маркерами категорий.
```

### 4. VLM-описание кадра камеры (/vlm/describe)

```
Опиши кадр с городской камеры видеонаблюдения.
Фокус: есть ли аномалии (скопление людей, авария, дым, препятствие)?
Если ничего необычного — верни {"anomaly": false, "description": "спокойная сцена"}.
Верни JSON: {"anomaly": bool, "description": "...", "confidence": 0.0-1.0}
```

## ⚡ RSCIT-фреймворк для проекта

Каждый промпт City Pulse должен содержать:

- **R** (Роль): «Ты — аналитик городских жалоб / редактор сводки / vision-модель»
- **S** (Контекст): домен Нижневартовск, источник (TG/VK/пользователь), категория
- **C** (Ограничения): JSON-only, на русском, до N знаков, no hallucinations
- **I** (Инструкция): классифицируй / сравни / опиши
- **T** (Шаблон): точная JSON-схема вывода

## 🛡 Анти-галлюцинация для адресов

```
Извлекай адрес ТОЛЬКО из предоставленного текста.
Если точный адрес (улица + номер дома) отсутствует — верни {"address": null}.
Не придумывай адреса. Адресный фильтр маркирует только жалобы с конкретным адресом.
```

## 📊 Чек-лист аудита промпта

- [ ] Роль/персона задана (аналитик / редактор / vision)
- [ ] Формат вывода явно указан (JSON-схема)
- [ ] Edge-cases: пустой текст, текст без адреса, нерусский язык
- [ ] Язык: русский (для пользовательского интерфейса)
- [ ] Галлюцинации: для адресов/фактов — «скажи не знаю если нет»
- [ ] Тест на 5+ примерах из реальных жалоб Нижневартовска
- [ ] Версионирование в git (промпты — это код)

## 🔧 Fallback-стратегия

```python
# Псевдокод fallback-цепочки в проекте
async def classify_complaint(text: str) -> dict:
    # 1. Z.AI (основной)
    try:
        return await zai_classify(text)
    except (ZAIError, TimeoutError):
        pass
    # 2. LiteLLM → Ollama (локальный)
    try:
        return await litellm_classify(text)  # через litellm:4000
    except (LiteLLMError, OllamaError):
        pass
    # 3. Keyword fallback (детерминированный)
    return keyword_classify(text)  # без ИИ
```
