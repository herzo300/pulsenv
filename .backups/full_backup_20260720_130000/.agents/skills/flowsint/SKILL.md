# flowsint: OSINT & Threat Intelligence Graph Platform

`flowsint` — это графовая платформа для исследования угроз (Threat Intelligence) и OSINT-анализа. Она помогает строить взаимосвязи между сетевыми адресами, Telegram/VK аккаунтами, сообщениями и подозрительной активностью.

## 🚀 Назначение в проекте City Pulse
- **Анализ злоумышленников:** Выявление спамеров, ботов и координаторов ложных сообщений о происшествиях.
- **Интеграция данных:** Импорт подозрительных IP-адресов, ID пользователей Telegram/VK и связывание их в единый граф взаимосвязей.
- **Анализ утечек и сетевой активности:** Мониторинг источников угроз.

## 🛠️ Запуск платформы

Платформа разворачивается с помощью Docker Compose.

1. Перейдите в каталог скилла:
   ```bash
   cd .agents/skills/flowsint
   ```
2. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```
3. Запустите стек сервисов (API, Web UI, Neo4j):
   ```bash
   docker compose -f docker-compose.dev.yml up -d
   ```
4. Откройте интерфейс в браузере: `http://localhost:3000`

## 📊 Основные компоненты
- **neo4j:** Графовая база данных для хранения связей (пользователи, адреса, телефоны, инциденты).
- **flowsint-api:** Бэкенд на Node.js/NestJS для управления импортом и обогащения данных.
- **flowsint-app:** Фронтенд на React/Next.js для визуализации графов.
- **flowsint-enrichers:** Модули обогащения данных (IPinfo, Shodan, VirusTotal и др.).
