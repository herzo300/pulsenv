# Blender & Three.js 3D Scene Builder Skill

## Назначение
Этот скилл предназначен для автоматического создания и генерации 3D-сцен, объектов благоустройства (детские площадки, парковые зоны, малые архитектурные формы) и подгонки перспектив поверх онлайн-потоков камер Нижневартовска.

## Основные шаги

1. **Генерация Blender Python (bpy) Скриптов**:
   - Параметрическое создание GLTF/GLB объектов (скамейки, горки, качели, осветительные столбы, спортивные снаряды).
   - Экспорт готовых моделей в `c:\Soobshio_project\services\Frontend\assets\3d\` или хранилище VPS.

2. **Интеграция с Three.js / Flutter 3D Canvas**:
   - Настройка ортографической и перспективной камеры под угол конкретной RTSP-камеры.
   - Масштабирование и освещение 3D-сцены под время суток (day/night) для бесшовного наложения на видеопоток.

3. **Инструкция использования**:
   - Вызывать при запросе пользователя на создание новых 3D-моделей или настройку 3D-режима виртуального благоустройства.
