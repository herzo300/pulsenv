# Anthropic Cybersecurity Skills

Набор навыков и инструментов для проведения анализа кибербезопасности, реагирования на инциденты, поиска угроз и оценки уязвимостей.

## Использование
Этот навык предоставляет обширную базу знаний и сценариев по реагированию на инциденты, аудиту облачной инфраструктуры, тестированию на проникновение и эмуляции атак.
