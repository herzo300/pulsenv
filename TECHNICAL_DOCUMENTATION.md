# 🩺 СообщиО — Техническая Документация (v3.0)

## 📌 Обзор Проекта
**СообщиО (City Pulse)** — платформа автоматизированного мониторинга городских проблем Нижневартовска. Система сканирует социальные сети (Telegram/VK), классифицирует инциденты с помощью ИИ, геокодирует адреса и маркирует проблемы на интерактивной карте в мобильном приложении. Автопубликация в канал @monitornv.

---

## 🏗 Архитектура Системы (Standalone Timeweb)
Проект развернут в Docker-контейнерах на сервере Timeweb (полная автономность).

### 🧩 Компоненты (Docker Compose)
1. **API Gateway (FastAPI)** — порт `8080`, обработка запросов от приложения
2. **PostgreSQL** — основное хранилище данных
3. **Redis** — кэширование и очереди
4. **Monitoring Worker** — мониторинг 8+ TG-каналов + VK-пабликов
5. **Camera Probe** — проверка состояния городских камер
6. **Ollama** — локальный LLM-сервер (Gemma 4 E4B — текст + визион)
7. **LiteLLM** — унифицированный AI-прокси
8. **Frigate NVR** — видеонаблюдение и детекция объектов
9. **Nginx** — обратный прокси, HTTPS, раздача Flutter Web

### 🔄 Конвейер обработки
1. Monitoring Worker захватывает сообщение из TG/VK
2. Спам-фильтр отсеивает рекламу и нерелевантный контент
3. ИИ (LiteLLM/Ollama) классифицирует по категории и извлекает адрес
4. **Адресный фильтр**: маркируются ТОЛЬКО проблемы с конкретным адресом (улица + номер дома)
5. Геокодирование адреса → координаты на карте
6. Сохранение в БД + публикация в @monitornv + push-уведомления

## 💾 База Данных (SQLite / PostgreSQL)
**Основные таблицы:**
- `Reports` — городские инциденты с координатами и категориями
- `Users` — профили пользователей приложения
- `DailyDigest` — ежедневный AI-анализ обстановки в городе
- `CameraAlerts` — алерты от Camera Watchdog
- `GeoSubscriptions` — push-подписки по геозонам

---

## 📱 Мобильное Приложение (Flutter)
- **Платформа**: Android (ARM64)
- **Сетевой слой**: `http://45.153.68.59:8080/api`
- **Ключевые функции**:
  - Интерактивная карта с маркерами инцидентов (каждый по своему адресу)
  - Просмотр городских камер (Pride/NV-City)
  - Ежедневный AI-анализ (бегущая строка)
  - Mesh-сеть для автономной связи в ЧС
  - Настройки уведомлений по категориям и геозонам

---

## 🤖 AI-провайдеры (цепочка fallback)
1. **Z.AI (GLM-5 Turbo / GLM-4V)** — основной облачный провайдер (текст + vision)
2. **LiteLLM → Ollama (Gemma 4)** — локальный, автономный (текст + vision)
3. **Keyword** — детерминистический fallback без ИИ

---

## 🛠 Развертывание
```bash
docker compose up -d --build
```
Все ключи изолированы в `.env` внутри Docker-контейнера.
