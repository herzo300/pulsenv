# DWG Memory Pack

Windows-инструмент для извлечения структуры DWG из AutoCAD, просмотра в окне, сохранения "памяти" чертежа и генерации AutoLISP-правок.

## Что внутри

- `lisp/DWG_EXPORT_INDEX.lsp` - AutoLISP-экспортер структуры DWG в JSON.
- `RUN_GUI.bat` - запуск Windows-окна для анализа JSON.
- `app/dwg_memory_gui.py` - GUI на Python/Tkinter.
- `app/dwg_analyzer.py` - анализатор, отчеты, CSV и генератор AutoLISP-правок.
- `lisp/DWG_APPLY_FIXES.lsp` - базовые функции применения правок в AutoCAD.

## Быстрый сценарий

1. Распакуй архив в удобную папку.
2. Открой DWG в AutoCAD.
3. Выполни `APPLOAD` и загрузи:

   ```text
   lisp/DWG_EXPORT_INDEX.lsp
   ```

4. В командной строке AutoCAD выполни:

   ```text
   DWG_EXPORT_INDEX
   ```

5. Сохрани JSON рядом с чертежом, например:

   ```text
   my_plan_dwg_index.json
   ```

6. Запусти:

   ```text
   RUN_GUI.bat
   ```

7. В окне нажми `Открыть JSON`.

## Что выгружается

Экспортер сохраняет:

- метаданные DWG;
- слои;
- блоки;
- layouts;
- все найденные объекты из `ssget "_X"`;
- handle, type, layer, layout, color, linetype, name, text;
- точки из DXF group codes 10-18;
- атрибуты INSERT-блоков;
- полный список group code/value для каждого объекта, насколько AutoLISP может сериализовать эти значения.

Это не бинарная копия DWG. Это поисковый индекс структуры и данных, который можно хранить, сравнивать, анализировать и использовать для генерации правок.

## Окно GUI

В GUI можно:

- смотреть сводку;
- смотреть слои;
- смотреть блоки;
- искать объекты по handle/type/layer/layout/text/name/attributes;
- сохранять снимок в `Документы/DWG_Memory`;
- делать Markdown-отчет;
- экспортировать таблицу объектов в CSV;
- подготовить AutoLISP-файл с типовыми правками.

## Генерация и применение правок

Вкладка `Правки` умеет подготовить:

- смену цвета слоя;
- переименование слоя;
- перенос объекта по handle на слой;
- смену цвета объекта;
- замену текста по handle;
- удаление объекта по handle.

После сохранения GUI создаст файл вроде:

```text
apply_generated_fixes.lsp
```

Как применить:

1. Сделай копию DWG.
2. Открой копию в AutoCAD.
3. Выполни `APPLOAD`.
4. Загрузи созданный `apply_generated_fixes.lsp`.
5. Выполни команду:

   ```text
   DWG_MEMORY_APPLY_GENERATED
   ```

Сгенерированный файл сам загрузит `lisp/DWG_APPLY_FIXES.lsp` по абсолютному пути из этой распакованной папки.

## Геодезические чертежи

Пакет может индексировать и помогать править геодезические DWG, если данные представлены обычными AutoCAD-объектами: точки, полилинии, тексты, блоки, подписи, контуры, слои.

Ограничения:

- Civil 3D COGO points, surfaces, alignments, profiles, parcels и другие AEC-объекты могут выгрузиться как proxy/custom entities или частично.
- Юридически значимые кадастровые/геодезические изменения нужно проверять в профильном ПО и человеком-специалистом.
- Для полной читаемости Civil 3D лучше дополнительно экспортировать данные в LandXML/CSV/DXF.

## Требования

- AutoCAD с поддержкой AutoLISP.
- Python 3.11+ для GUI. Внешние Python-библиотеки не нужны.

## CLI-режим

Можно построить отчет без GUI:

```bat
RUN_ANALYZER.bat path\to\drawing_dwg_index.json
```

Или напрямую:

```bat
python app\dwg_analyzer.py path\to\drawing_dwg_index.json
```

## Безопасность

- Всегда применяй правки на копии DWG.
- Перед запуском просматривай generated `.lsp`.
- Handle объектов может изменяться после некоторых операций AutoCAD, поэтому правки лучше генерировать и применять на той же версии чертежа, из которой сделан JSON.
